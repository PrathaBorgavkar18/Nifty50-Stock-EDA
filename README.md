
# Nifty 50 Stock Market EDA 📈

## Project Overview
Exploratory Data Analysis of top 10 Nifty 50 stocks from 2023 to 2025.

## What I Analyzed
- Stock price movements over 2 years
- Daily returns distribution
- Correlation between stocks
- Volatility (Risk) of each stock
- Cumulative returns - ₹100 invested growth

## Tools & Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Key Findings
- HDFCBANK gave highest return (~120% growth)
- ITC and BHARTIARTL remained in loss
- All stocks show nearly normal distribution of returns
- Low correlation between stocks shows good diversification
